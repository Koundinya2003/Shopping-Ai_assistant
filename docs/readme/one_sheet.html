AI grocery assistant

Your cart, read back to you.

A grocery companion that looks at what is already in your cart and suggests what goes with it, with a reason for every pick. Rules choose the products, an LLM ranks and explains them, and nothing breaks when the LLM is not there.

Next.js front end · FastAPI back end · OpenRouter for the language model

How a pick is made

Rules pick the shelf. The model explains the choice.

Every cart change runs the same short pipeline. Teal steps are deterministic, berry steps involve the language model.

Fallback first

Three tiers, so the shopper never sees an error.

If the API is down, slow or returns bad JSON, the system steps down a tier. Failures are logged on the server, never shown to the user.

1

AI ranking

The model ranks the top candidates and writes the full reasoning. Good answers are cached.
